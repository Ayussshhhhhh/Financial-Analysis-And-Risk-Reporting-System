# Business user guide (one page)

1. Open the approved Power BI app and choose your role's page from the top navigation.
2. Set the date range first. Use region, product category, customer segment, and channel filters only where the page provides them. Your assigned region is enforced by access policy.
3. Select a chart bar or category to cross-filter other visuals. Use **Reset filters** to return to the page default.
4. On eligible pages, right-click a region/product/order and choose **Drill through** to see permitted detail. The target page retains the selected context.
5. Use the freshness card to confirm the last completed refresh. Report stale data or a failed refresh through the BI support contact configured by your organization.
6. Export is available only if enabled for your role. Never forward exported customer detail outside approved channels.

For access problems, contact the BI platform owner through the organization's approved support channel. This sample repository has no real support mailbox or tenant.
